## MacroStudio v1.4.0

- **Shared macros with no storage cap.** Create MacroStudio macros that are shared across all your characters, without using Account or Character macro slots. Your existing native macros remain available alongside them.
- **Quick, per-character keybindings.** Use the new Keybind button below Category and Tags. Left-click and press a key, middle/extra mouse button, or scroll direction to bind it. Esc cancels; right-click clears. Assigned keys appear in a readable format such as Alt + 1.
- **Drag from the list or editor.** Place saved macros onto your action bars by dragging a list entry or the editor icon. For a shared MacroStudio macro, this creates and reuses a linked native copy that stays updated when you save. Each linked action-bar copy uses one Character or Account slot; direct keybindings use no native slots.
- **Copy snapshots where you need them.** The new Copy to dropdown offers Current Character, Account Macros, and MacroStudio Macros. Copies keep the original name, icon and body, while leaving the source snapshot unchanged. Full native destinations are disabled individually.
- **Five named color styles.** Choose Warcraft (default), Legacy, Emerald, Violet, or Ember in Settings, then Reload UI. Legacy retains the original blue/gray design. One Color Style selector replaces the separate Appearance section.
- **Helpful checks while editing.** See line-specific hints for common macro problems, including incomplete commands, malformed condition brackets, and repeated #showtooltip lines. Hover over the summary for details. These checks never rewrite your macro or block Save.

Existing macros, Favorites, categories, tags, and settings are preserved. MacroStudio macros retain the 255-character body limit.

Open MacroStudio with `/ms` or `/macrostudio`.
